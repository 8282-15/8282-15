## 🤖 AI / Agent

我对 Agent 的兴趣，主要来自一个很朴素的想法：能不能让 AI 不只是回答问题，而是真的参与到一个流程里。

比如读取资料、调用工具、拆任务、写接口、总结结果。现在我还在学习 LangChain 和 LangGraph，也会尝试用 FastAPI 把这些能力包装成后端服务，再用 Vue 做一个能看的界面。

我比较关心这些问题：

- Agent 怎么从 demo 变得更稳定？
- LLM 调工具时，怎么减少乱跑和误判？
- RAG 怎么做得更像“可靠参考”，而不是“看起来像参考”？
- Vue、FastAPI、LangGraph 怎么组合成一个完整的小项目？
- AI 编程工具到底适合帮我做什么，不适合替我做什么？
